# Exercise 10: Clean Up Resources (Optional)

[← Previous Exercise: Test AI Agent](09-Test-Agent.md) | [Home](../README.md)

---

## Objective

Clean up and remove the Microsoft Fabric workspace and Microsoft Foundry resources created during this workshop.

---

## Overview

You can keep your workspace, lakehouse, eventhouse, and Fabric IQ ontology to continue exploring Fabric IQ capabilities. If you want to clean up and remove all resources created in this workshop, follow the step-by-step instructions below.

---

## Steps

### Step 1: Clean Up Microsoft Fabric Workspace
1. In Microsoft Fabric, locate the left navigation bar.
2. Select the icon for your workspace (`LamnaHealthcareWS`) to view all items it contains.
3. Select **Workspace settings** from the top toolbar.
4. In the **General** section, scroll to the bottom and select **Remove this workspace**.
5. Select **Delete** to confirm workspace deletion.

---

### Step 2: Clean Up Microsoft Foundry Project (Optional)
1. Open the [Microsoft Foundry portal](https://ai.azure.com).
2. Select **Management center** (or **Settings**).
3. Under **Projects**, select `LamnaHealthcareFoundryProject`.
4. Select **Delete project** and confirm deletion.

---

## Expected Result

All workshop assets (`LamnaHealthcareWS` workspace, Lakehouse, Eventhouse, `LamnaHealthcareOntology`, and `LamnaHealthcareAgent`) are removed.
